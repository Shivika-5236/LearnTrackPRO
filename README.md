# LearnTrackPRO

LearnTrackPRO is a comprehensive student productivity platform designed to manage courses, study sessions, tasks, and academic analytics in one place.

## Project Structure

- **LearnTrackPRO/**: The mobile application built with Expo and React Native.
- **backend/**: The Node.js/Express server providing API services and data persistence.

## Features

- **Course Management**: Track courses, assignments, and grades.
- **Study Sessions**: Intelligent focus blocks with countdown timers and history logging.
- **Task Management**: Prioritized to-do lists with status tracking (Not Started, Doing, Completed).
- **Analytics**: Data-driven insights into study habits and academic progress.
- **AI Assistant**: "Aria" - an integrated AI tutor to help with study queries.

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Expo Go (for mobile testing)

### Setup

1. **Frontend (App)**:
   ```bash
   cd LearnTrackPRO
   npm install
   npx expo start
   ```

2. **Backend (API)**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```

## Tech Stack

- **Frontend**: Expo, React Native, TypeScript, Expo Router, SQLite.
- **Backend**: Node.js, Express, MongoDB/Mongoose.
- **AI**: Google Gemini API.

## Platform Support

- **iOS**: Fully Supported
- **Android**: Fully Supported
- **Web**: Partial support (Limited by SQLite local storage)
